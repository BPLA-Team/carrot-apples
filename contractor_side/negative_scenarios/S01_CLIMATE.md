# S-01. Негативные сценарии микроклимата

```mermaid
sequenceDiagram
    participant S as Сервис
    participant H as D-01 Хаб
    participant D as D-04 Датчик температуры и влажности
    participant B as D-05 Батарея
    participant C as D-06 Кондиционер
    participant U as D-07 Увлажнитель
    alt 🔴 D-01 Хаб
        S->>H: Запрос изменения профиля
        H->>H: Активный профиль вне согласованных пределов
        Note over H: Нарушение G-01
    else 🔴 D-02 Колонка
        Note over H: У колонки нет роли в локальном климатическом цикле
    else 🔴 D-03 Датчик движения
        Note over H: Движение не используется при расчёте режима
    else 🔴 D-04 Датчик температуры и влажности
        D->>H: Показания, постоянно требующие увлажнения
        H->>U: Продолжать увлажнение без независимого срока отключения
        Note over H,U: G-01 не обеспечена при утрате управляемости
    else 🔴 D-05 Батарея
        H->>B: Остановить нагрев перед охлаждением
        H->>C: Включить охлаждение
        Note over B,C: Нагрев продолжается — нарушение G-01
    else 🔴 D-06 Кондиционер
        H->>C: Остановить охлаждение перед нагревом
        H->>B: Включить нагрев
        Note over B,C: Охлаждение продолжается — нарушение G-01
    else 🔴 D-07 Увлажнитель
        H->>U: Прекратить увлажнение
        Note over U: Увлажнение продолжается — нарушение G-01
    else 🔴 D-08 Камера
        Note over H: Кадры не используются при расчёте режима
    else 🔴 D-09 Пылесос
        Note over H: Состояние уборки не используется при расчёте режима
    end
```
