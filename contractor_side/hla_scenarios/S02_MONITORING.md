# S-02. Наблюдение на исходной HLA

```mermaid
sequenceDiagram
    actor R as Жилец
    participant W as Веб-интерфейс жильца
    participant S as Внешний сервис
    participant H as Хаб
    participant D as Датчик движения
    participant C as Камера
    D->>H: Движение обнаружено
    H->>H: Сохранить временную отметку
    R->>W: Открыть наблюдение
    W->>S: Запросить сеанс из внешней сети
    S->>H: Передать запрос хабу
    alt Сеанс открыт
        loop Пока сеанс открыт
            C->>H: Кадры
            H-->>S: Кадры и актуальные отметки
            S-->>W: Передать поток
        end
        R->>W: Завершить просмотр
        W->>S: Закрыть сеанс
        S->>H: Передать запрос закрытия
        H-->>S: Выдача остановлена
        S-->>W: Передать результат
    else Сеанс не открыт
        H-->>S: Отказ
        S-->>W: Отказ или недоступность хаба
    end
```
