# Базовые сценарии на исходной HLA

| ID   | Диаграмма                       | Как компоненты реализуют сценарий                                                                                                                                                                                                                                        |
| ---- | ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| S-01 | [Микроклимат](S01_CLIMATE.md)   | Хаб сохраняет допустимые настройки из веб-интерфейса, колонки и кнопок климатических устройств. Автоматика использует действующую уставку и учитывает локальные отключения. Защитный контур описан в итоговой политике. |
| S-02 | [Наблюдение](S02_MONITORING.md) | Датчик движения передаёт событие хабу по LAN. По запросу веб-интерфейса жильца через внешний сервис хаб включает камеру и выдаёт видео и отметки тем же внешним маршрутом. |
| S-03 | [Уборка](S03_VOICE_CLEANING.md) | Колонка передаёт команду хабу, а хаб — пылесосу по LAN. Отчёт и тайм-аут различаются. Системный статус запрашивается через веб-интерфейс жильца и внешний сервис. |
| S-04 | [Музыка](S04_MUSIC.md)          | Медиатека и плеер находятся внутри D-02. Хаб, сервис и остальные устройства штатно не участвуют.                                                                                                                                                                         |
