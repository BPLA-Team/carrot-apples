# S-01. Микроклимат на исходной HLA

```mermaid
sequenceDiagram
    actor R as Жилец
    participant W as Веб-интерфейс жильца
    participant S as Сервис
    participant K as Умная колонка
    participant H as Хаб
    participant D as Датчик температуры и влажности
    participant B as Батарея
    participant C as Кондиционер
    participant U as Увлажнитель
    alt Через веб-интерфейс
        R->>W: Задать целевые температуру и влажность
        W->>S: Отправить запрос из внешней сети
        S->>H: Запрошенный профиль
    else Голосом
        R->>K: Задать уставку числом или изменить на шаг
        K->>H: Величина и значение или направление шага
    else Кнопками климатического устройства
        R->>C: Нажать + или − (пример на кондиционере)
        C->>H: Изменить целевую температуру на шаг
        Note over B,U: Батарея меняет температуру, увлажнитель — влажность
    end
    alt Допустимое изменение
        H->>H: Сохранить новую уставку локально
    else Недопустимое изменение
        H->>H: Оставить прежнюю уставку
    end
    Note over W,U: Хаб сообщает результат через источник запроса<br/>Автоматика не перезаписывает уставку
    loop Пока локальный контур работает
        D->>H: Показания температуры и влажности
        H->>H: Рассчитать режим по уставкам с учётом локальных отключений
        alt Нужен нагрев
            H->>C: Выключить охлаждение
            H->>B: Включить нагрев с уставкой
        else Нужно охлаждение
            H->>B: Выключить нагрев
            H->>C: Включить охлаждение с уставкой
        else Температура в целевой зоне
            H->>B: Выключить нагрев
            H->>C: Выключить охлаждение
        end
        H->>U: Включить или выключить увлажнение
        Note over H,U: Локальный цикл не обращается к сервису
    end
```
