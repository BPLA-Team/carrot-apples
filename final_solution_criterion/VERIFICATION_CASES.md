# Приёмочные проверки на модели

Таблица задаёт начальные условия, модельное событие и наблюдаемый результат. Для каждого случая допущения действуют, если явно не проверяется выход за пределы модели. Это проектные проверки; при реализации их нужно перенести на симулятор или стенд с проверяемыми портами и состояниями.

| ID   | Сценарий / цель   | Исходное состояние и событие                                                                                                                                         | Наблюдаемый результат                                                                                                                                                                                                          |
| ---- | ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| N-01 | S-01 / G-01       | Сохранён допустимый профиль. Сервис передаёт просроченное, повторное, неподписанное либо выходящее за согласованный диапазон изменение.                              | T сохраняет прежний активный профиль; F-06 не получает допуска вследствие отклонённого изменения.                                                                                                                              |
| N-02 | S-01 / G-01       | Активен допуск нагрева. Поступает допустимый запрос охлаждения; отдельно проверяется, что обычный контроллер батареи продолжает просить нагрев.                      | Сначала снят физический допуск нагрева, затем возможен допуск охлаждения; оба допуска никогда не активны одновременно. Тот же критерий проверяется при переходе в обратную сторону.                                            |
| N-03 | S-01 / G-01       | Нагрев, охлаждение или увлажнение разрешены. Исчезают свежие показания, прерывается связь T→C либо срабатывает соответствующая независимая защита.                   | После истечения действующего допуска выход снят; срабатывание защиты снимает затронутый допуск независимо от запроса автоматики. Старое разрешение не продлевается при повторе.                                                |
| N-04 | S-02 / G-02       | Нет сеанса. Приходят отметка движения и кадр; открыть просмотр пытается неавторизованный внешний клиент.                                                             | Допускается ограниченная локальная отметка, но нет сеанса и выдачи; внешнего маршрута от M к сервису нет.                                                                                                                      |
| N-05 | S-02 / G-02       | Панель с разрешённой идентичностью открывает сеанс; затем закрывает его либо теряет канал.                                                                           | Во время сеанса данные получает только эта панель. После завершения новые кадры не выдаются, отложенные кадры удаляются из очереди сеанса.                                                                                     |
| N-06 | S-03, S-04 / G-03 | Интерфейс колонки подаёт штатный запуск и остановку, а также модельные запросы профиля, просмотра и управления иным устройством.                                     | Только запуск и остановка преобразуются в команды привязанному пылесосу. Нештатные запросы не меняют профиль, климат и сеанс; музыка не открывает сетевых полномочий.                                                          |
| N-07 | S-03 / G-04       | Принята заявка. Проверить отдельно своевременный отчёт, поломку или молчание, опоздавший отчёт и отчёт по другому идентификатору.                                    | Своевременный сопоставленный ответ отмечен как `DeviceReport`; при отсутствии допустимого ответа — `Unconfirmed`. Поздний ответ не меняет терминальный статус. Панель показывает состояние T, даже если колонка сообщает иное. |
| N-08 | S-01…S-04 / G-05  | Есть сохранённый допустимый профиль и исправны соответствующие локальные участники. Сервис отключён до начала сценариев и, в другом прогоне, во время их выполнения. | Локальный климатический цикл, просмотр, запуск/остановка уборки и локальная музыка продолжаются. Новая облачная настройка может быть недоступна; локальные сценарии её не ждут.                                                |

Полный перебор ролей исходной HLA — девять вариантов на каждый из четырёх сценариев — находится в [негативных сценариях](../contractor_side/negative_scenarios/ANALYSIS.md). Критерий приёмки реализации: ожидаемые результаты выше воспроизводятся и подтверждены A-01…A-06 для заявленной конфигурации. Если предположение не выполнено, связанная цель требует нового обоснования.
