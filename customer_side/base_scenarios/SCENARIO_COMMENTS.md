# Базовые сценарии использования

| ID | Диаграмма | Условия и особенности |
|---|---|---|
| S-01 | [Настройка и поддержание микроклимата](S01_CLIMATE.md) | Профиль задаётся через веб-интерфейс; уставки также можно менять голосом или кнопками по LAN без сервиса. Хаб сохраняет допустимые изменения. Потеря локальных показаний может приостановить регулирование. |
| S-02 | [Отметки о движении и живое видео](S02_MONITORING.md) | Движение создаёт отметку на хабе, но не открывает видеосеанс. Жилец открывает и закрывает сеанс через веб-интерфейс и внешний сервис; видеоархива нет. |
| S-03 | [Голосовое управление уборкой](S03_VOICE_CLEANING.md) | Колонка передаёт хабу команды запуска и остановки по LAN без обращения к сервису. Отчёт пылесоса не доказывает, что уборка выполнена. Системный статус можно посмотреть через веб-интерфейс жильца при доступном внешнем сервисе. |
| S-04 | [Воспроизведение музыки](S04_MUSIC.md) | Локальная коллекция колонки позволяет включать и останавливать музыку без сервиса. Этот сценарий сам по себе не управляет другими устройствами. |
